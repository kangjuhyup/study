# Study

공부한 내용을 주제별로 정리하는 공간입니다. 개념과 함께 직접 작성한 재현 코드, 실험 결과, 분석 과정과 배운 점을 기록합니다.

## 학습 기록

| 폴더 | 내용 |
| --- | --- |
| [oom-snapshot](./oom-snapshot/README.md) | Node.js OOM 재현, Heap Snapshot 비교와 메모리 참조 분석 |
| [k6-loadgen-isolation](./k6-loadgen-isolation/README.md) | 공유 자원의 부하 생성기 OOM과 M1 Mini 분리 시험 해석 |

## 기록 방식

- 주제별 폴더에 학습 자료를 모읍니다.
- 각 폴더의 README에 학습 목적, 실행 환경, 재현 방법과 결과를 정리합니다.
- 상세 분석은 해당 폴더의 문서로 연결하고, 새 주제는 위 학습 목록에 추가합니다.
- 기존 실험 결과와 원본 자료를 보존하고, 재실행 결과는 별도로 저장합니다.

실행 환경은 각 폴더의 README와 runtime pin을 따릅니다.
