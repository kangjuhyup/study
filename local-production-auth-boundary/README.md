# 로컬·운영 인증 경계 학습

애플리케이션 dev 실행 + Docker Compose 인프라를 사용하는 로컬 환경과, Kubernetes·Istio 기반 운영 구성의 인증 경로를 비교합니다. 필요한 검증 단계를 로컬에 최소한으로 재현하는 방향을 정리합니다.

- [실행 가능한 최소 샘플](./samples/README.md): Docker Compose로 실행하고 12개 인증 시나리오 확인
- [한국어 기술 글 초안](./blog/index.md)
- [최소 로컬 인증 환경 구성 가이드](./local-guide.md): 구현 준비, Compose·Envoy 설정 예시, 연결·거부·장애 검증

인증 경계의 설계 초안과 실행 가능한 학습용 샘플을 함께 관리합니다. 샘플은 Docker Compose에서 실행해 12개 요청을 검증했습니다. 실제 프로젝트와 운영 환경의 연결 검증은 구성 가이드에 따라 별도로 진행합니다.
